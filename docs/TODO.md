## 🧠 学习建议

1. **每天写代码**：哪怕 20 分钟也比一次学 5 小时效果好
2. **先跑通再深究**：看不懂生命周期没关系，先让 borrow checker 通过再说
3. **善用编译器**：Rust 编译器的错误信息是最好的老师——仔细读！
4. **遇到不懂的 → 看标准库源码**：`Vec`、`Option`、`Result` 的源码是顶级教学材料
5. **每学完一章 → 写一个对应的小程序**：不要只看书
