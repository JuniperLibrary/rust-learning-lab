## 一、前置准备

### 系统要求

| 项目 | 最低要求 |
|------|---------|
| 内存 | ≥ 4 GB（大型项目建议 ≥ 8 GB） |
| 硬盘 | ≥ 10 GB 剩余空间 |
| 系统 | Windows 7+ / macOS 10.12+ |
| 网络 | 需要稳定网络（国内用户建议配置镜像加速，见[第六节](#六国内镜像加速可选)） |

### Rust 工具链组成

安装 Rust 会获得以下核心工具：

| 工具 | 用途 |
|------|------|
| `rustc` | Rust 编译器 |
| `cargo` | 包管理器与构建工具（类似 npm/pip） |
| `rustup` | 工具链管理器（安装/切换/更新 Rust 版本） |
| `rustfmt` | 代码格式化工具 |
| `clippy` | 代码 lint 工具（捕获常见错误和不规范写法） |

## 二、macOS 安装

### 步骤 1：安装 Xcode 命令行工具

Rust 需要链接器（linker）来编译程序。macOS 上通过 Xcode 命令行工具提供：

```bash
xcode-select --install
```

- 会弹出安装窗口，点击"安装"并等待完成（约 400 MB）
- 安装后 `cc`、`clang`、`ld` 等工具可在终端正常使用
- **不一定要装完整的 Xcode（十几个 GB）**，命令行工具就够用

### 步骤 2：安装 rustup

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

- 终端中运行后会显示安装选项
- 输入 `1` 选择默认安装（自动安装最新稳定版）
- 安装脚本会自动添加 `~/.cargo/bin` 到 `PATH`
- 如果安装成功，末尾会显示：`Rust is installed now. Great!`

### 步骤 3：配置环境变量

安装脚本会自动配置 PATH。如果新终端中 `rustc` 命令不可用，手动执行：

```bash
source "$HOME/.cargo/env"
```

或者将以下内容添加到 shell 配置文件（永久生效）：

```bash
# 根据你使用的 shell 编辑对应的配置文件：
# Bash → ~/.bash_profile
# Zsh  → ~/.zshrc (macOS 默认)

export PATH="$HOME/.cargo/bin:$PATH"
```

### macOS 快速安装汇总

```bash
# 1. 安装 Xcode 命令行工具
xcode-select --install

# 2. 安装 rustup（一路默认）
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 3. 生效环境变量
source "$HOME/.cargo/env"

# 4. 验证
rustc --version
cargo --version
```

## 三、Windows 安装

### 步骤 1：安装 MSVC C++ 构建工具 ⚠️ 必装

**Windows 上 Rust 依赖 Microsoft 的 C++ 链接器（linker）。** 没有这个步骤，`cargo build` 会报 `link.exe not found`。

#### 方式 A：安装 Visual Studio 2022 Build Tools（推荐）

1. 访问 [Visual Studio 下载页](https://visualstudio.microsoft.com/downloads/)
2. 找到 **Visual Studio 2022 Build Tools**（不是完整的 VS IDE）
3. 运行安装程序，在**工作负载**选项卡中勾选：
   - **使用 C++ 的桌面开发**（Desktop development with C++）
4. 点击安装（约 2-5 GB，视网络情况）

> 注意：Build Tools 需要有效的 Visual Studio 许可证。社区版（Community）对个人开发者、学生和开源贡献者免费。

#### 方式 B：已安装 Visual Studio IDE 怎么办？

如果你已安装 Visual Studio 2022/2019，打开 **Visual Studio Installer**，找到已安装的版本，点击"修改"，勾选 **使用 C++ 的桌面开发** 工作负载即可。

### 步骤 2：安装 rustup

#### 方式 A：WinGet（推荐，最新版 Windows 10/11 内置）

```powershell
winget install Rustlang.Rustup
```

#### 方式 B：手动安装 rustup-init.exe

1. 访问 [https://rustup.rs](https://rustup.rs/)
2. 下载 `rustup-init.exe`（64 位系统选 x86_64 版本）
3. 运行安装程序
4. 出现命令行提示时，输入 `1` 选择默认安装
5. 安装程序会自动下载 MSVC 工具链（推荐用于 Windows 开发）

### 步骤 3：配置环境变量

安装程序默认会配置 PATH。如果 `rustc` 命令不可用，检查：

1. 确保 `%USERPROFILE%\.cargo\bin` 已添加到系统 PATH
2. **重启终端**（或打开全新的 CMD / PowerShell 窗口）
3. PATH 修改可能需要重启才能完全生效

### ⚡ 性能优化：禁用 Windows Defender 扫描

Rust 的 cargo 会在 `%USERPROFILE%\.cargo` 下缓存大量文件，Windows Defender 的实时扫描会显著拖慢编译速度。

**建议将以下路径添加到 Windows Defender 排除列表：**

```
%USERPROFILE%\.cargo
```

操作路径：Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 排除项 → 添加排除项 → 文件夹

### Windows WSL 用户

如果你使用 WSL（Windows Subsystem for Linux），可以直接在 WSL 终端中用 macOS/Linux 的安装方式：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

WSL 不需要 MSVC 构建工具，因为它用的是 Linux 工具链。

### Windows 快速安装汇总

```powershell
# 1. 安装 MSVC C++ 构建工具（先手动下载安装）
#    从 https://visualstudio.microsoft.com/downloads/ 下载 Build Tools

# 2. 安装 rustup（两种方式选其一）
winget install Rustlang.Rustup   # 方式 A：WinGet
# 或下载 rustup-init.exe 手动安装   # 方式 B

# 3. 打开新终端，验证
rustc --version
cargo --version

# 4. （可选）禁止 Defender 扫描 .cargo 目录
# 设置 → Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 排除项
```

## 四、验证安装

### 4.1 检查版本

```bash
rustc --version
# 预期输出示例：rustc 1.85.0 (4d91de4e4 2025-02-17)

cargo --version
# 预期输出示例：cargo 1.85.0 (d73d1c879 2025-01-20)

rustup --version
# 预期输出示例：rustup 1.27.1 (54dd3d00f 2024-04-24)
```

> 版本号可能不同（Rust 每 6 周发布一个新版本），只要不报错就是安装成功。

### 4.2 创建并运行第一个项目

```bash
# 创建新项目
cargo new hello_rust
cd hello_rust

# 编译并运行
cargo run
```

预期输出：

```
   Compiling hello_rust v0.1.0 (...)
    Finished `dev` profile [unoptimized + debuginfo] in 0.47s
     Running `target/debug/hello_rust`
Hello, world!
```

### 4.3 检查安装的组件

```bash
rustup component list --installed
```

应包含以下组件：

- `rustc` / `cargo` / `rustfmt` / `clippy` — 核心工具链
- `rust-std` — Rust 标准库
- `rust-docs` — 本地文档

## 五、编辑器配置

### 5.1 Visual Studio Code（推荐）

#### 安装步骤

1. 下载安装 [VS Code](https://code.visualstudio.com/)
2. 安装 **rust-analyzer** 扩展（搜索 `rust-lang.rust-analyzer`）

#### rust-analyzer 核心功能

| 功能 | 说明 |
|------|------|
| 代码补全 | 智能自动完成，支持泛型/生命周期推导 |
| 内联错误 | 在编辑器中直接显示编译错误（无需手动运行编译） |
| 跳转到定义 | `F12` 跳转到类型/函数定义处 |
| 查找引用 | 查看所有使用位置 |
| 自动格式化 | 保存时自动运行 `rustfmt` |
| 类型提示 | 显示变量/表达式的推断类型 |

#### 推荐的其他 VS Code 扩展

| 扩展名 | 用途 |
|--------|------|
| `CodeLLDB` | Rust 调试支持（断点/变量查看/调用栈） |
| `Even Better TOML` | 语法高亮 `Cargo.toml` |
| `crates` | `Cargo.toml` 中显示 crate 最新版本 |
| `Error Lens` | 将错误/警告显示在代码行后面（更直观） |

#### VS Code 设置推荐（`settings.json`）

```json
{
    "rust-analyzer.check.command": "clippy",
    "editor.formatOnSave": true,
    "[rust]": {
        "editor.defaultFormatter": "rust-lang.rust-analyzer"
    }
}
```

### 5.2 其他编辑器

| 编辑器 | 插件 |
|--------|------|
| CLion | 内置 Rust 插件（付费）或 IntelliJ Rust |
| Vim/Neovim | `rust-analyzer` LSP 集成（通过 `coc.nvim` 或 `nvim-lspconfig`） |
| Helix | 内置 Rust LSP 支持 |
| Zed | 原生 Rust 编辑器，内置 rust-analyzer |

## 六、国内镜像加速（可选）

> 国内直接访问 `crates.io` 和 `static.rust-lang.org` 可能较慢。
> 配置以下镜像后，安装依赖和更新工具链会快很多。

### 6.1 rustup 镜像（加速安装和更新）

在你的 shell 配置文件中添加以下环境变量（macOS: `~/.zshrc`, Windows PowerShell: `$PROFILE`）：

```bash
# 以中科大镜像为例（也可用清华/南大/华为云等）
export RUSTUP_DIST_SERVER="https://mirrors.ustc.edu.cn/rust-static"
export RUSTUP_UPDATE_ROOT="https://mirrors.ustc.edu.cn/rust-static/rustup"
```

这样在执行 `curl -sSf https://sh.rustup.rs | sh` 或 `rustup update` 时就会走镜像。

### 6.2 Cargo 镜像（加速 crate 下载）

创建或编辑 `~/.cargo/config.toml`（Windows: `%USERPROFILE%\.cargo\config.toml`）：

```toml
[source.crates-io]
replace-with = "ustc"

[source.ustc]
registry = "sparse+https://mirrors.ustc.edu.cn/crates.io-index/"
```

> `sparse+` 协议需要 Cargo 1.68+（2023 年初发布的版本），使用稀疏索引比传统的 git 协议快很多。

#### 其他可选镜像源

| 镜像 | 地址 |
|------|------|
| 中科大 (USTC) | `sparse+https://mirrors.ustc.edu.cn/crates.io-index/` |
| 清华 (TUNA) | `sparse+https://mirrors.tuna.tsinghua.edu.cn/crates.io-index/` |
| 上海交大 (SJTU) | `sparse+https://mirror.sjtu.edu.cn/crates.io-index/` |
| 华为云 | `sparse+https://repo.huaweicloud.com/repository/crates.io-index/` |
| Rust 官方 (rsproxy) | `sparse+https://rsproxy.cn/crates.io-index/` |

## 七、工具链管理

### 更新 Rust

Rust 每 6 周发布一个新版本，建议定期更新：

```bash
rustup update
```

### 查看已安装的工具链

```bash
rustup show
```

### 安装多版本工具链

```bash
rustup install stable      # 稳定版（日常开发）
rustup install beta        # 测试版（试用新功能）
rustup install nightly     # 每日构建（尝鲜/使用不稳定特性）
```

### 切换默认工具链

```bash
rustup default stable      # 切回稳定版（默认）
rustup default nightly     # 切换到 nightly
```

### 为特定项目指定工具链

在项目根目录创建 `rust-toolchain.toml`：

```toml
[toolchain]
channel = "stable"
```

团队项目中加上此文件，确保所有成员使用相同版本的 Rust。

### 添加/移除组件

```bash
rustup component add clippy
rustup component add rustfmt
rustup component remove clippy
```

### 卸载 Rust

```bash
rustup self uninstall
```

## 八、常用 Cargo 命令速查

| 命令 | 说明 |
|------|------|
| `cargo new <name>` | 创建新项目（默认 binary 类型） |
| `cargo new <name> --lib` | 创建库项目 |
| `cargo build` | 编译项目（debug 模式） |
| `cargo build --release` | 编译项目（release 模式，带优化） |
| `cargo run` | 编译并运行 |
| `cargo check` | **快速检查代码是否能通过编译**（不生成可执行文件，比 build 快很多） |
| `cargo test` | 运行测试 |
| `cargo fmt` | 格式化代码（自动调整空格/缩进等） |
| `cargo clippy` | 运行 lint 检查（建议在 git commit 前跑一次） |
| `cargo add <crate>` | 添加依赖（自动写入 `Cargo.toml`） |
| `cargo remove <crate>` | 移除依赖 |
| `cargo update` | 更新依赖到语义版本范围内的最新版 |
| `cargo doc --open` | 生成当前项目的文档并在浏览器中打开 |
| `cargo clean` | 清理编译产物（`target/` 目录） |

### 推荐工作流

```bash
# 开发阶段
cargo check          # 快速检查是否有编译错误（每次修改后跑）
cargo run            # 运行看效果

# 提交前
cargo fmt            # 格式化代码
cargo clippy         # static analysis 检查代码质量
cargo test           # 跑测试
cargo build          # 最终确认能编译
```

## 九、常见问题与排错

### 问题 1：`rustc: command not found`

**原因**：`~/.cargo/bin` 未在 PATH 中。

**解决**：

- macOS/Linux：运行 `source "$HOME/.cargo/env"` 或重启终端
- Windows：检查 `%USERPROFILE%\.cargo\bin` 是否在系统 PATH 中，重启终端

### 问题 2：`link.exe not found`（Windows）

**原因**：未安装 MSVC C++ 构建工具。

**解决**：

1. 下载安装 [Visual Studio Build Tools](https://visualstudio.microsoft.com/downloads/)
2. 确保勾选 **使用 C++ 的桌面开发**
3. 重启终端后重新 `cargo build`

### 问题 3：编译速度慢

**原因**：可能是 Windows Defender 实时扫描或 CPU 性能限制。

**解决**：

- Windows：将 `%USERPROFILE%\.cargo` 添加到 Defender 排除列表
- macOS/Linux：使用 `cargo check` 而不是 `cargo build` 快速检查语法
- 使用 `mold` 或 `lld` 作为链接器可以显著加速（macOS/Linux）

### 问题 4：`cargo build` 非常慢（卡在 Updating index）

**原因**：访问 crates.io 索引网络延迟高（国内常见）。

**解决**：配置国内镜像源（见[第六节](#六国内镜像加速可选)），然后运行：

```bash
cargo build  # 第一次会更新索引，之后就不再需要了
```

### 问题 5：`rustup update` 失败

**原因**：网络问题。

**解决**：

```bash
# 设置镜像后重试
export RUSTUP_DIST_SERVER="https://mirrors.ustc.edu.cn/rust-static"
export RUSTUP_UPDATE_ROOT="https://mirrors.ustc.edu.cn/rust-static/rustup"
rustup update
```

### 问题 6：安装后 `cargo run` 成功但 VS Code 仍报错

**原因**：rust-analyzer 尚未完成索引。

**解决**：等待 VS Code 右下角 rust-analyzer 状态变为就绪（绿色），或点击状态栏触发重新加载。必要时关闭 VS Code 重开。
