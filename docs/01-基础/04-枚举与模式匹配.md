# 枚举与模式匹配

## 一句话理解

> **Rust 没有 `null`！用 `Option<T>` 表达"可能有值"，用 `match` 强制你处理所有情况。**

## 定义枚举

枚举可以携带数据——这比其他语言的枚举强大得多：

```rust
enum Coin {
    Yuan(u32),       // 可以携带 u32 类型数据
    Jiao,
    Fen,
}

// 还可以携带不同类型
enum Message {
    Quit,                       // 没有数据
    Move { x: i32, y: i32 },   // 匿名结构体
    Write(String),              // 单个 String
    ChangeColor(i32, i32, i32), // 三个 i32
}
```

## Match 必须穷举（Exhaustive）

```rust
match my_coin {
    Coin::Yuan(v) => println!("{} 元", v),
    Coin::Jiao    => println!("一角"),
    Coin::Fen     => println!("一分"),
    // 少了任何分支 → ❌ 编译错误！
}
```

**这是 Rust 最强大的安全特性之一**：你不可能忘记处理某个分支。新增一个枚举变体时，编译器会告诉你所有需要修改的 match 位置。

## 通配符 `_`

当你只关心部分情况时：

```rust
match my_coin {
    Coin::Yuan(v) => println!("{} 元", v),
    _ => println!("零钱"),    // 其他所有情况
}
```

`_` 匹配所有未列出的情况，但用它意味着你放弃了穷举检查的好处。

## if let —— "我只关心一种情况"

```rust
let some_number = Some(5);

match some_number {
    Some(val) => println!("{}", val),
    None => (),               // 为了满足穷举写的"空"分支
}

// 等价于更简洁的：
if let Some(val) = some_number {
    println!("{}", val);
}
```

`if let` 是 `match` + 只处理一种模式的语法糖。

## while let —— 循环直到不匹配

```rust
let mut stack = vec![1, 2, 3];
while let Some(top) = stack.pop() {
    println!("{}", top);  // 3, 2, 1
}
```

## 解构（Destructuring）

Match 不仅能匹配枚举，还能**解构**复杂类型：

```rust
// 解构结构体
struct Point { x: i32, y: i32 }
let p = Point { x: 10, y: 20 };
let Point { x, y } = p;     // x = 10, y = 20
println!("({}, {})", x, y);

// 解构元组
let triple = (1, 2, 3);
let (a, b, c) = triple;
println!("{} {} {}", a, b, c);

// 在 match 中解构嵌套枚举
enum Location { Point { x: i32, y: i32 }, Name(String) }
let loc = Location::Point { x: 5, y: 10 };
match loc {
    Location::Point { x, y } => println!("({}, {})", x, y),
    Location::Name(n) => println!("{}", n),
}
```

## Option<T> —— Rust 没有 null

```rust
enum Option<T> {
    Some(T),
    None,
}

let some_number = Some(5);          // Option<i32>
let absent_number: Option<i32> = None;  // 必须标明类型

// Option<T> 和 T 是不同类型！
let x: i32 = 5;
let y: Option<i32> = Some(5);
let sum = x + y;  // ❌ 编译错误！i32 和 Option<i32> 不能直接运算
```

**这意味着**：Rust 编译器强迫你在使用"可能为空"的值之前先检查它。这是无数空指针异常的解决方案。

## Option 的常用方法（组合子）

Option 有很多实用方法，避免写繁琐的 match：

```rust
let val = Some(5);

// map：如果有值则转换
let doubled = val.map(|v| v * 2);     // Some(10)

// unwrap_or：有值取值，无值用默认
let n = val.unwrap_or(0);             // 5

// unwrap_or_else：有值取值，无值执行闭包
let n = val.unwrap_or_else(|| 0);

// and_then：链式操作（flat map）
let result = val.and_then(|v| {
    if v > 0 { Some(v * 2) } else { None }
});

// is_some / is_none：判断
val.is_some();  // true
val.is_none();  // false

// expect：有值返回，无值 panic 并打印自定义消息
val.expect("should have a value");
```

## Result<T, E> —— 可能出错的操作

```rust
enum Result<T, E> {
    Ok(T),
    Err(E),
}

use std::fs::File;

let f = File::open("hello.txt");  // Result<File, std::io::Error>

match f {
    Ok(file) => println!("打开成功"),
    Err(e) => println!("打开失败: {}", e),
}
```

Result 会在**错误处理**章节深入学习。它与 Option 遵循同一套组合子模式：

```rust
let result: Result<i32, &str> = Ok(10);
result.map(|v| v * 2);            // Ok(20)
result.unwrap_or(0);              // 10（Err 时返回默认值）
result.unwrap();                  // 10（Err 时会 panic）
```

## 模式匹配的其他技巧

```rust
// 范围匹配
let score = 85;
match score {
    90..=100 => println!("A"),
    80..=89  => println!("B"),
    70..=79  => println!("C"),
    _        => println!("不及格"),
}

// 多个模式用 |
let x = 2;
match x {
    1 | 2 => println!("一或二"),
    3     => println!("三"),
    _     => println!("其他"),
}

// 匹配守卫（match guard）
let pair = (2, -2);
match pair {
    (x, y) if x == y => println!("相等"),
    (x, y) if x + y == 0 => println!("相反数"),
    (x, _) => println!("x = {}", x),
}

// @ 绑定：匹配时同时绑定到变量
let id: Option<i32> = Some(100);
match id {
    Some(id @ 1..=50) => println!("小号: {}", id),
    Some(id @ 51..=100) => println!("中号: {}", id),
    Some(id) => println!("大号: {}", id),
    None => println!("无"),
}

// matches! 宏
let x = Some(5);
matches!(x, Some(5));             // true
matches!(x, Some(v) if v > 3);    // true
```

## 常见误区

```rust
// ❌ 忘记 Option<i32> 和 i32 不同
let a: i32 = 5;
let b: Option<i32> = Some(5);
// let sum = a + b;  // ❌

// ✅ 必须先解包
let sum = a + b.unwrap_or(0);  // 10

// ❌ 不必要的 match
if option.is_some() {
    let val = option.unwrap();  // 双重检查，浪费
}

// ✅ 直接处理
if let Some(val) = option {
    // 使用 val
}

// ❌ 过度使用 unwrap()
option.unwrap();  // None 时直接 panic！
// ✅ 用 unwrap_or / expect / match
```
