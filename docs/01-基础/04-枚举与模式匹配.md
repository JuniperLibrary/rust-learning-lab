# 枚举与模式匹配

## 一句话理解

> **Rust 没有 `null`！用 `Option<T>` 表示"可能有值"，用 `match` 强制处理所有情况。**

## 定义枚举

```rust
enum Coin {
    Yuan(u32),    // 可以携带数据
    Jiao,
    Fen,
}
```

## Match 必须穷举

```rust
match my_coin {
    Coin::Yuan(v) => println!("{} 元", v),
    Coin::Jiao    => println!("一角"),
    Coin::Fen     => println!("一分"),
    // 少了任何分支 → 编译错误
}
```

## Option<T> —— 代替 null

```rust
enum Option<T> {
    Some(T),     // 有值
    None,        // 没值
}
```

```rust
let some_number = Some(5);
let absent_number: Option<i32> = None;

match absent_number {
    Some(val) => println!("{}", val),
    None      => println!("没有值"),
}
```

## 关键点

- `match` 必须**穷举所有情况**，编译器强制你考虑边界
- `if let` 是 `match` 的语法糖，只关注一种模式时用：

```rust
if let Some(val) = some_number {
    println!("{}", val);
}
```
