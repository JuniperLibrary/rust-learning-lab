# 所有权（Ownership）

## 一句话理解

> **每个值在任意时刻有且只有一个所有者（owner）。**

```rust
let s1 = String::from("你好，世界");
let s2 = s1;                    // 所有权从 s1 转移到 s2
// println!("{}", s1);          // ❌ 编译错误：s1 已失效
println!("{}", s2);             // ✅
```

## 所有权规则

1. Rust 中**每个值**都有一个**所有者**（owner）
2. **同一时刻只能有一个所有者**
3. 当所有者离开作用域，值被自动释放（drop）

## 栈 vs 堆

| 特性 | 栈 (Stack) | 堆 (Heap) |
|------|-----------|-----------|
| 速度 | 快（压入/弹出固定大小） | 慢（需分配/释放） |
| 大小 | 编译期已知 | 运行时可变 |
| 例子 | `i32`, `bool`, 固定数组 | `String`, `Vec` |

**简单类型**（实现了 `Copy` trait）赋值是拷贝，不转移所有权：

```rust
let x = 42;
let y = x;             // ✅ 拷贝，x 依然有效
println!("{}", x);     // ✅
```

## 函数传参 = 所有权转移

```rust
let s = String::from("hello");
some_fn(s);            // 所有权被移入函数
// println!("{}", s);  // ❌ 已失效
```
