# 所有权（Ownership）

## 一句话理解

> **每个值在任意时刻有且只有一个所有者（owner）。**

```rust
let s1 = String::from("你好，世界");
let s2 = s1;                    // 所有权从 s1 转移到 s2
// println!("{}", s1);          // ❌ 编译错误：s1 已失效
println!("{}", s2);             // ✅
```

## 三条铁律

1. Rust 中**每个值**都有一个**所有者**（owner）
2. **同一时刻只能有一个所有者**
3. 当所有者离开作用域，值被**自动释放**（`drop`）

## 栈 vs 堆

| 特性 | 栈 (Stack) | 堆 (Heap) |
|------|-----------|-----------|
| 速度 | 快（压入/弹出） | 慢（分配/释放） |
| 大小 | 编译期已知 | 运行时动态 |
| 管理 | CPU 自动 | 需要手动或通过所有权 |
| 典型值 | `i32`, `bool`, `f64`, 数组 | `String`, `Vec`, `Box` |
| 赋值语义 | 拷贝（Copy） | 移动（Move） |

Rust 的所有权系统根本上是在解决堆内存的管理问题——**不需要 GC，也不用手动 free**。

## 移动（Move）语义

```rust
let s1 = String::from("hello");
let s2 = s1;       // s1 被"移动"到 s2

// 背后发生了什么？
// - s1 的指针/长度/容量被复制到 s2
// - Rust 立即把 s1 标记为"已失效"
// - 堆上的字符串数据没有被复制（零成本！）
// - s1 离开作用域时不会 double free（因为已失效）
```

**移动是浅拷贝 + 源失效**。这是 Rust 零成本抽象的核心——不 copy 堆数据，只是转移指针所有权。

## Clone：如果你真的想深拷贝

```rust
let s1 = String::from("hello");
let s2 = s1.clone();     // ✅ 堆数据被完整复制
println!("{} {}", s1, s2); // 都有效
```

`clone()` 是**显式的**——你知道这里发生了成本较高的堆拷贝。这是 Rust 的理念：**显式优于隐式**。

## Copy：栈上数据的"自动拷贝"

实现了 `Copy` trait 的类型，赋值是拷贝而不是移动：

```rust
let x = 42;
let y = x;             // ✅ 拷贝（实现了 Copy）
println!("{} {}", x, y); // 都有效
```

### Copy vs Clone 对比

| | Copy | Clone |
|---|---|---|
| 代价 | 低（按位拷贝） | 可能很高（堆拷贝） |
| 是否显式 | 隐式自动 | 必须调用 `.clone()` |
| 适用 | 纯栈类型 | 任意类型 |
| 约束 | 类型不能包含 Drop | 无 |
| 例子 | `i32`, `bool`, `f64` | `String`, `Vec` |

### 哪些类型实现了 Copy？

- 所有整数类型：`i32`, `u32`, `u64` 等
- 所有浮点类型：`f32`, `f64`
- 布尔类型：`bool`
- 字符类型：`char`
- 只包含 Copy 类型的元组：`(i32, i32)`
- 只包含 Copy 类型的数组：`[i32; 3]`

**非 Copy 类型**：`String`, `Vec`, `Box` 等堆分配类型。

## Drop：资源释放自动机

当一个所有者离开作用域时，Rust 自动调用 `drop()`：

```rust
{
    let s = String::from("hello");
    // 使用 s
    // ...
}   // ← 这里自动调用 s.drop()，释放堆内存
```

这叫做 **RAII（Resource Acquisition Is Initialization）**：
- 资源获取即初始化（在构造时获取）
- 资源释放即在析构时（在离开作用域时自动释放）
- 不用写 `close()`、`free()`、`dispose()` 之类的代码
- 即使在函数中途 `return` 或 `panic`，资源也会被释放（栈 unwinding）

## 函数调用 = 所有权转移

```rust
fn main() {
    let s = String::from("hello");
    take_ownership(s);
    // println!("{}", s);  // ❌ 所有权已转移，s 已失效

    let x = 42;
    copy_value(x);        // ✅ x 实现了 Copy，只是拷贝了一份
    println!("{}", x);    // ✅ x 依然有效
}

fn take_ownership(some_string: String) {
    println!("{}", some_string);
} // ← 在这里 some_string 被 drop 释放

fn copy_value(some_int: i32) {
    println!("{}", some_int);
}
```

## 返回值转移所有权

```rust
fn main() {
    let s1 = gives_ownership();         // 从函数返回值接收所有权
    let s2 = String::from("hello");
    let s3 = takes_and_gives_back(s2);  // s2 被移进函数，s3 接收返回值
    // s2 已失效
}

fn gives_ownership() -> String {
    String::from("from function")
}

fn takes_and_gives_back(s: String) -> String {
    s  // 返回又把所有权交出去
}
```

**所有权转移就像"传递令牌"**——不存在"丢失"的情况，只有"用完还回来"或"被回收"。

## 元组解构：返回多个值 + 归还所有权

```rust
fn main() {
    let s1 = String::from("hello");
    let (s2, len) = calculate_length(s1);  // s1 移入，拿到 s2（归还）和 len
}

fn calculate_length(s: String) -> (String, usize) {
    let len = s.len();
    (s, len)  // 把 s 的所有权还回去
}
```

这样写虽然麻烦，但引出下一节——**借用**让我们不用来回传递所有权。

## 部分移动（Partial Move）

```rust
struct Point { x: i32, y: String }

let p = Point { x: 10, y: String::from("hello") };

// 可以部分移出结构体的字段
let x = p.x;            // ✅ i32 是 Copy 类型，p 仍然有效
let y = p.y;            // ✅ String 被移出，但 p 不能再使用了
// println!("{:?}", p); // ❌ 编译错误：p 的部分字段已被移动

// 解构也是类似
let Point { x, y } = p; // 同上，y 被移动
```
