# 结构体与方法（Struct & impl）

## 三种结构体

### 1. 具名字段结构体（最常见）

```rust
struct Hero {
    name: String,
    hp: i32,
    is_alive: bool,
}

let mut hero = Hero {
    name: String::from("亚瑟"),
    hp: 100,
    is_alive: true,
};
hero.hp = 50;  // 字段需要实例是 mut 才能修改
```

### 2. 元组结构体（Tuple Struct）

```rust
struct Color(i32, i32, i32);  // 字段没有名字
struct Point2D(f64, f64);

let black = Color(0, 0, 0);
let origin = Point2D(0.0, 0.0);

// 元组结构体是一个独立类型！
// Color(0,0,0) 和 Point2D(0.0,0.0) 不兼容

// 访问方式
println!("R: {}", black.0);
println!("G: {}", black.1);
```

### 3. 单元结构体（Unit-like Struct）

```rust
struct Empty;             // 没有字段！
struct Ground;            // 用于标记类型，类似一个"类型标签"

// 常用于实现 Trait 但没有数据要存的情况
trait Noise {
    fn make_noise(&self);
}
impl Noise for Ground {
    fn make_noise(&self) {
        println!("咚！");
    }
}
```

## 字段初始化简写（Field Init Shorthand）

```rust
fn new_hero(name: String, hp: i32) -> Hero {
    Hero {
        name,               // 等价于 name: name
        hp,                 // 等价于 hp: hp
        is_alive: true,
    }
}
```

## 结构体更新语法（Struct Update Syntax）

```rust
let hero1 = Hero {
    name: String::from("亚瑟"),
    hp: 100,
    is_alive: true,
};

let hero2 = Hero {
    name: String::from("兰斯洛特"),
    ..hero1               // 从 hero1 复制剩余字段
};
// 注意：hero1.name 没有被复制，而是被移动了！
// 如果你不想移动 name，需要 .clone()
```

## 方法（impl 块）

```rust
impl Hero {
    // 关联函数（不接收 self，类似"静态方法"）
    fn new(name: String) -> Self {
        Self { name, hp: 100, is_alive: true }
    }

    // 不可变方法（&self = self: &Self）
    fn show_status(&self) {
        println!("{} 血量: {}", self.name, self.hp);
    }

    // 可变方法（&mut self = self: &mut Self）
    fn take_damage(&mut self, damage: i32) {
        self.hp -= damage;
    }

    // 获取所有权的方法（不常见，但可以）
    fn die(self) -> String {
        println!("{} 阵亡！", self.name);
        self.name   // 返回 name，所有权被移出
    }
}
```

### 方法调用的自动解引用

```rust
let hero = Hero::new(String::from("亚瑟"));
let hero_ref = &hero;
let hero_box = Box::new(hero);

hero_ref.show_status();   // ✅ 自动解引用
hero_box.show_status();   // ✅ 自动解引用（Box -> &Hero）
```

Rust 会在调用方法时自动插入 `*` 和 `&`，让你不用操心引用层级。

## 多个 impl 块

```rust
impl Hero {
    fn new(name: String) -> Self { /* ... */ }
    fn show_status(&self) { /* ... */ }
}

impl Hero {     // ✅ 可以分开写
    fn take_damage(&mut self, damage: i32) {
        self.hp -= damage;
    }
}
```

逻辑上分类有用，编译时会合并为一个。

## 关联常量

```rust
impl Hero {
    const MAX_HP: i32 = 100;

    fn is_alive(&self) -> bool {
        self.hp > 0
    }
}

println!("{}", Hero::MAX_HP);  // 100
```

## derive 宏（自动实现 Trait）

```rust
// 自动为结构体实现 Debug、Clone、PartialEq
#[derive(Debug, Clone, PartialEq)]
struct Hero {
    name: String,
    hp: i32,
    is_alive: bool,
}

let h1 = Hero::new("亚瑟");
println!("{:?}", h1);              // Debug 格式化
let h2 = h1.clone();              // 克隆
println!("{}", h1 == h2);         // 相等比较
```

常用 derive：
| Trait | 效果 |
|-------|------|
| `Debug` | 支持 `{:?}` 格式化输出 |
| `Clone` | 支持 `.clone()` 方法 |
| `Copy` | 赋值自动拷贝（需所有字段都是 Copy） |
| `PartialEq` | 支持 `==` 和 `!=` |
| `Eq` | 严格相等（在 PartialEq 之上） |
| `Hash` | 可用作 HashMap 的 key |
| `Default` | 支持 `Hero::default()` 默认值 |
| `PartialOrd` | 支持 `<` `>` 比较 |

## 经典模式：Newtype

```rust
struct UserId(i32);           // 简单封装，类型安全
struct ProductId(String);     // 比直接用 i32/String 更好

fn lookup_user(id: UserId) { /* ... */ }
fn lookup_product(id: ProductId) { /* ... */ }

lookup_user(UserId(1));
// lookup_user(ProductId("abc"));  // ❌ 类型安全！不会搞混
```

## 经典模式：Builder

```rust
struct HeroBuilder {
    name: String,
    hp: i32,
    is_alive: bool,
}

impl HeroBuilder {
    fn new(name: &str) -> Self {
        Self {
            name: name.to_string(),
            hp: 100,
            is_alive: true,
        }
    }
    fn hp(mut self, hp: i32) -> Self {
        self.hp = hp;
        self
    }
    fn build(self) -> Hero {
        Hero {
            name: self.name,
            hp: self.hp,
            is_alive: self.is_alive,
        }
    }
}
```

## 常见误区

```rust
// ❌ 尝试修改 &self 中的字段
impl Hero {
    fn bad_method(&self) {
        // self.hp += 1;  // ❌ &self 是只读借用
    }
}

// ❌ 忘记 self 参数的类型
// impl Hero {
//     fn bad_new(name: String) { ... }  // 这是关联函数，不是方法
// }

// ⚠️ 方法名与字段名冲突时 → 方法优先
impl Hero {
    fn hp(&self) -> i32 {   // 如果定义了此方法
        self.hp              // 访问字段需要 self.hp
    }
}
```
