# 结构体与方法（Struct & impl）

## 结构体：自定义数据类型

```rust
struct Hero {
    name: String,
    hp: i32,
    is_alive: bool,
}

let mut hero = Hero {
    name: String::from("亚瑟"),
    hp: 100,
    is_alive: true,
};
hero.hp = 50;  // 需要 mut 才能修改
```

## 方法（impl 块）

```rust
impl Hero {
    // 关联函数（构造函数）
    fn new(name: String) -> Self {
        Self { name, hp: 100, is_alive: true }
    }

    // 不可变方法（&self）
    fn show_status(&self) {
        println!("{} 血量: {}", self.name, self.hp);
    }

    // 可变方法（&mut self）
    fn take_damage(&mut self, damage: i32) {
        self.hp -= damage;
    }
}
```

## 关键点

- `Self` 是当前类型的简写
- `self` / `&self` / `&mut self` 是 `hero: Hero` / `&Hero` / `&mut Hero` 的语法糖
- **没有 `self` 参数 → 关联函数**，用 `::` 调用，如 `Hero::new()`
- **有 `self` 参数 → 方法**，用 `.` 调用，如 `hero.show_status()`
