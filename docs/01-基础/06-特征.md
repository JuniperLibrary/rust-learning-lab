# 特征（Trait）

## 一句话理解

> **Trait 定义"一组行为"，类似其他语言的接口（interface），但没有继承。**

## 定义与实现

```rust
// 定义契约
trait Attackable {
    fn take_damage(&mut self, damage: i32);
    fn is_dead(&self) -> bool;
}

// 为类型实现
struct Monster { name: String, hp: i32 }

impl Attackable for Monster {
    fn take_damage(&mut self, damage: i32) {
        self.hp -= damage;
    }

    fn is_dead(&self) -> bool {
        self.hp <= 0
    }
}
```

## 关键点

- **没有继承**：Rust 不用父类/子类，用 Trait 共享行为
- **孤儿规则**：实现 trait 时，trait 和类型至少有一个是当前 crate 的
- Trait 可以包含**默认实现**
- Trait 可以作为**参数约束**：`fn foo(item: &impl Attackable)`

## 对比其他语言

| 概念 | Rust | Java | Go |
|------|------|------|----|
| 行为抽象 | Trait | Interface | Interface |
| 继承 | ❌ 无 | ✅ extends | ❌ 无 |
| 默认实现 | ✅ 有 | ✅ default | ❌ 无 |
| 隐式实现 | ✅ 自动derive | ❌ | ❌ |
