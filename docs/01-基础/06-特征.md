# 特征（Trait）

## 一句话理解

> **Trait 定义"一组行为"，类似其他语言的接口（interface），但没有继承。**

## 定义与实现

```rust
// 1. 定义契约
trait Attackable {
    fn take_damage(&mut self, damage: i32);
    fn is_dead(&self) -> bool;
}

// 2. 为类型实现
struct Monster { name: String, hp: i32 }

impl Attackable for Monster {
    fn take_damage(&mut self, damage: i32) {
        self.hp -= damage;
        println!("怪物 [{}] 惨叫一声", self.name);
    }

    fn is_dead(&self) -> bool {
        self.hp <= 0
    }
}
```

## 默认实现

```rust
trait Attackable {
    fn take_damage(&mut self, damage: i32) {
        println!("受到 {} 点伤害", damage);
    }
    fn is_dead(&self) -> bool;
}

// Monster 只需实现 is_dead，take_damage 用默认的
impl Attackable for Monster {
    fn is_dead(&self) -> bool {
        self.hp <= 0
    }
}
```

默认实现可以被覆盖，类似"模板方法"模式。

## Trait 作为参数

### 语法一：`impl Trait`（简便方式）

```rust
fn attack(target: &mut impl Attackable) {
    target.take_damage(10);
}
```

### 语法二：泛型约束（等价，更正式）

```rust
fn attack<T: Attackable>(target: &mut T) {
    target.take_damage(10);
}
```

### 语法三：多个约束

```rust
fn print_and_attack(target: &mut (impl Attackable + Display)) { }
fn print_and_attack<T: Attackable + Display>(target: &mut T) { }
```

### 语法四：where 子句（约束很多时）

```rust
fn complex_function<T, U>(t: &T, u: &U)
where
    T: Attackable + Display + Clone,
    U: Attackable + Debug,
{ }
```

## `impl Trait` vs `dyn Trait`

| | `impl Trait` | `dyn Trait` |
|---|---|---|
| 分派方式 | **静态分派**（编译期） | **动态分派**（运行时） |
| 性能 | 快（无虚函数调用） | 略慢（虚函数表） |
| 大小 | 编译期已知 | 必须放在指针后面 |
| 适用场景 | 性能敏感，类型已知 | 多种类型集合 |

```rust
// 静态分派：每种类型生成一份函数代码
fn process_static(item: &impl Attackable) { }

// 动态分派：运行时通过虚表调用
fn process_dynamic(items: &[&dyn Attackable]) {
    for item in items {
        item.take_damage(5);
    }
}

// 常见做法：Box<dyn Trait>
let monsters: Vec<Box<dyn Attackable>> = vec![
    Box::new(Monster { name: "史莱姆".into(), hp: 20 }),
    Box::new(Boss { name: "魔王".into(), hp: 500 }),
];
```

## 孤儿规则（Orphan Rule）

> **实现 trait 时，trait 和类型至少有一个是在当前 crate 中定义的。**

```rust
// 在你的 crate 中
use std::fmt::Display;

// ✅ 可以：MyType 是你定义的
impl Display for MyType { }

// ❌ 不可以：Display 和 Vec<T> 都不是你定义的
// impl Display for Vec<String> { }

// ❌ 也不可以：两个都是外部的
// impl From<String> for Vec<u8> { }
```

这叫"孤儿规则"——防止不同 crate 对同一个类型实现同一个 trait 导致的冲突。

## 继承：Super Trait

Rust 没有类继承，但 trait 可以"继承"其他 trait：

```rust
trait Display {
    fn to_string(&self) -> String;
}

trait Printable: Display {  // Printable 的前提是实现了 Display
    fn print(&self) {
        println!("{}", self.to_string());
    }
}

// 实现 Printable 时也必须实现 Display
impl Display for MyStruct { /* ... */ }
impl Printable for MyStruct { /* ... */ }
```

## 关联类型（Associated Types）

```rust
pub trait Iterator {
    type Item;  // 关联类型：由实现者决定

    fn next(&mut self) -> Option<Self::Item>;
}

struct Counter { count: u32 }

impl Iterator for Counter {
    type Item = u32;  // 指定 Item 类型

    fn next(&mut self) -> Option<Self::Item> {
        self.count += 1;
        if self.count < 6 { Some(self.count) } else { None }
    }
}
```

关联类型让 trait 更灵活——每个实现者可以指定自己的输出类型。

## 标准库常用 Trait

```rust
// Debug：打印调试信息
#[derive(Debug)]
struct MyStruct;
println!("{:?}", MyStruct);  // Debug 格式

// Display：用户可读的格式
impl Display for MyStruct {
    fn fmt(&self, f: &mut Formatter<'_>) -> std::fmt::Result {
        write!(f, "MyStruct")
    }
}

// Default：默认值
#[derive(Default)]
struct Config {
    timeout: u32,    // 默认为 0
    retries: u32,    // 默认为 0
}

// Clone：显式拷贝
let cloned = original.clone();

// PartialEq / Eq：相等比较
#[derive(PartialEq, Eq)]
struct UserId(u32);
if user1 == user2 { /* 相等 */ }

// Into / From：类型转换
impl From<i32> for MyNumber {
    fn from(n: i32) -> Self { MyNumber(n) }
}
let n: MyNumber = 42.into();    // 使用 Into
let n = MyNumber::from(42);     // 等价，使用 From
```

## derive 宏的本质

```rust
// 这行宏：
#[derive(Debug, Clone, PartialEq)]
struct Point { x: i32, y: i32 }

// 等价于编译器自动生成了类似这样的代码：
// impl Debug for Point { ... }
// impl Clone for Point { ... }
// impl PartialEq for Point { ... }
```

你将来可以用**过程宏（proc macro）** 自己写这样的 `derive`。

## 标记 Trait（Marker Trait）

没有任何方法，只是"标记"类型具有某种属性：

```rust
// Copy：按位拷贝（隐式赋值）
// Sized：编译期大小已知（几乎所有类型默认都是 Sized）
// Send：可以跨线程安全传递
// Sync：可以跨线程安全共享引用

fn takes_copy<T: Copy>(val: T) { }
```

## 常见误区

```rust
// ❌ 不理解 impl Trait 和 dyn Trait 的区别
fn returns_attackable() -> impl Attackable {  // ✅ 返回单一类型
    Monster { name: "史莱姆".into(), hp: 20 }
}
// fn returns_dynamic(choice: bool) -> impl Attackable {  // ❌ 可能返回不同类型
//     if choice { Monster { .. } } else { Boss { .. } }
// }
// ✅ 用 Box<dyn Trait>
fn returns_dynamic(choice: bool) -> Box<dyn Attackable> {
    if choice { Box::new(Monster { .. }) } else { Box::new(Boss { .. }) }
}

// ❌ trait 对象不能返回 Self
trait Clone {
    fn clone(&self) -> Self;  // dyn Clone 不能调用此方法
}
// Box<dyn Clone> 是不合法的

// ❌ 孤儿规则
// impl Display for Vec<String> { }  // ❌ 两者都不是当前 crate 的
```
