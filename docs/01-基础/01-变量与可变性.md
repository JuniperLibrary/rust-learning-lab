# 变量与可变性

## 核心规则

- **变量默认不可变（immutable）** —— 这是 Rust 的安全底线
- **需要可变时，显式加 `mut`** —— 让代码的"可变意图"一目了然

```rust
let name = "Rust";      // 不可变
// name = "Java";        // ❌ 编译错误

let mut age = 10;       // 可变
age = 11;               // ✅
```

## 为什么默认不可变？

- **心智模型简单**：读到 `let x = ...` 就知道 x 不会变，不需要追踪后续代码
- **编译器优化**：编译器可以做出更多激进优化（常量传播等）
- **并发安全**：不可变变量天然可以在多线程间共享，不需要锁
- **减少 bug**：大量 bug 源于"不小心修改了不该改的变量"

## 变量遮蔽（Shadowing）

与 `mut` 不同，你可以重复使用 `let` 声明同名变量——这叫做**遮蔽**。

```rust
let x = 5;
let x = x + 1;      // ✅ 新 x 遮蔽旧 x，创建了一个新变量
let x = x * 2;      // ✅ 再次遮蔽
println!("{}", x);  // 12

// 更重要的是：遮蔽可以改变变量类型！
let msg = "hello";          // &str 类型
let msg = msg.len();        // 现在变成了 usize 类型
println!("{}", msg);        // 5
```

### `mut` vs Shadowing 对比

| | `mut` | Shadowing |
|---|---|---|
| 本质 | 修改同一变量 | 创建新变量，旧变量被隐藏 |
| 类型 | 不能改变 | **可以改变类型** |
| 生命周期 | 整个作用域 | 直到被再次遮蔽或离开作用域 |
| 场景 | 累加、循环计数器 | 值转换、类型变化 |

## const 与 static

除了 `let`，还有两种定义常量的方式：

```rust
// const：编译期常量，内联到使用处
const MAX_POINTS: u32 = 100_000;  // 必须标明类型

// static：全局变量（有固定内存地址）
static APP_NAME: &str = "Rust Lab";
static mut COUNTER: u32 = 0;      // 可变 static 需要用 unsafe 访问

// const 可以用于数组长度等编译期上下文
const ARRAY_SIZE: usize = 10;
let arr: [i32; ARRAY_SIZE] = [0; 10];
```

| | `let` | `const` | `static` |
|---|---|---|---|
| 运行时创建 | ✅ | ❌ 编译期计算 | ❌ 编译期固定 |
| 内存地址 | 栈上临时 | 无（内联） | ✅ 固定地址 |
| 可变性 | 可选 `mut` | ❌ 永远不可变 | 不可变（或 unsafe mutable） |
| 全局作用域 | ❌ 函数内 | ✅ | ✅ |

## 作用域与代码块

```rust
let x = 1;

let y = {
    let x = 2;          // 这个 x 遮蔽了外部的 x
    x + 1               // 代码块的"返回值"（没有分号）
};

println!("{} {}", x, y);  // 1 3（外部 x 不变）
```

- 代码块 `{ }` 有独立作用域
- 代码块最后一个表达式就是它的"返回值"
- 这在 Rust 中非常常见，比如 `let y = if cond { a } else { b };`

## 表达式（Expression）—— Rust 中"一切皆表达式"

Rust 的代码块、if/else、match 等都可以作为表达式返回值：

```rust
// if/else 是表达式
let age = 18;
let can_vote = if age >= 18 { "可以投票" } else { "不能投票" };
println!("{}", can_vote);  // "可以投票"

// match 也是表达式
let x = 3;
let description = match x {
    1 => "单个",
    2..=5 => "几个",
    _ => "很多",
};
println!("{}", description);  // "几个"

// 代码块 { } 最后一个表达式就是返回值
let result = {
    let a = 10;
    let b = 20;
    a + b  // 没有分号！这就是返回值
};
println!("{}", result);  // 30

// loop 也能用 break 返回值
let count = loop {
    break 42;
};
println!("{}", count);  // 42
```

**关键规则**：有分号 `;` → 语句（statement），不返回值；没分号 → 表达式（expression），返回一个值。这是 Rust 代码中非常常见的模式。

## 格式化输出

Rust 的 `println!` / `print!` / `format!` 使用**格式化字符串**：

```rust
// 基础占位符
println!("{} {}", "hello", 42);       // "hello 42"

// 位置参数
println!("{1} {0}", "world", "hello"); // "hello world"

// 命名参数
println!("{name} is {age}", name="Alice", age=30);

// Debug 输出（用于 Vec、结构体等复杂类型）
println!("{:?}", vec![1, 2, 3]);       // [1, 2, 3]

// 美观的 Debug 输出（换行+缩进）
println!("{:#?}", vec![1, 2, 3]);
// [
//     1,
//     2,
//     3,
// ]

// Display vs Debug
// {}     → Display（用户友好）
// {:?}  → Debug（开发者友好，需要 #[derive(Debug)]）

// 数字格式化
println!("{:b}", 255);   // 二进制: 11111111
println!("{:x}", 255);   // 十六进制: ff
println!("{:>10}", "右对齐");  // 右对齐，宽度 10
println!("{:<10}", "左对齐");  // 左对齐，宽度 10
```

## 常见误区

```rust
// ❌ 以为 let 可以重新赋值
let x = 5;
// x = 6;               // 编译错误！没有 mut

// ✅ 如果你想改，要么用 mut，要么 shadowing
let mut x = 5;
x = 6;                  // 可以

// ✅ 或者用 shadowing
let x = 5;
let x = 6;              // 创建新变量

// ❌ 混淆 mut 和 shadowing
let mut x = "hello";
x = 42;                 // ❌ 类型不匹配（mut 不能改变类型）
let x = 42;             // ✅ shadowing 可以改变类型
```
