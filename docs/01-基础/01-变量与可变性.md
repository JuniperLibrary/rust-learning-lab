# 变量与可变性

## 核心规则

- **变量默认不可变（immutable）** —— 这是 Rust 的安全底线
- **需要可变时，显式加 `mut`** —— 让代码的"可变意图"一目了然

```rust
let name = "Rust";      // 不可变
// name = "Java";        // ❌ 编译错误

let mut age = 10;       // 可变
age = 11;               // ✅
```

## 为什么默认不可变？

- 减少心智负担：读到 `let x = ...` 就知道 x 不会变
- 编译器可以做出更多优化
- 避免意外的数据修改（尤其是多线程场景）

## 关键点

- `mut` 不是"不好的"，而是一种**显式声明**：告诉读者和编译器"这个变量会被修改"
- 能用不可变就用不可变，需要修改再加 `mut`
