# 迭代器与闭包（Iterator & Closure）

## 闭包（Closure）

### 一句话理解

> **闭包是可以捕获环境变量的匿名函数。语法：`|参数| 表达式`**

```rust
// 基本语法
let add = |a, b| a + b;
println!("{}", add(2, 3));  // 5

// 多行闭包（用大括号）
let multiply = |a, b| {
    let result = a * b;
    println!("{} x {} = {}", a, b, result);
    result
};
```

### 闭包与函数的区别

```rust
// 普通函数：不能捕获外部变量
fn add_one(x: i32) -> i32 { x + 1 }

// 闭包：可以捕获外部变量
let base = 10;
let add_base = |x: i32| x + base;  // ✅ 捕获了 base
println!("{}", add_base(5));        // 15
```

### 闭包捕获方式

| 方式 | 效果 | 对应 Trait |
|------|------|-----------|
| `T` | 获取所有权（移动） | `FnOnce` |
| `&mut T` | 可变借用 | `FnMut` |
| `&T` | 不可变借用 | `Fn` |

```rust
let x = String::from("hello");

// FnOnce：消费 x（获取所有权）
let consume = || drop(x);  // 只能调用一次

// FnMut：可变借用
let mut y = 10;
let mut add_to_y = || y += 5;

// Fn：不可变借用（最常用）
let z = 42;
let print_z = || println!("{}", z);
```

### move 关键字：强制获取所有权

```rust
let s = String::from("hello");

// 不强制 move：闭包借用 s
let borrow = || println!("{}", s);

// 强制 move：闭包拿走 s 的所有权
let take = move || println!("{}", s);
// println!("{}", s);  // ❌ s 已被 move 进闭包
```

`move` 常用于**多线程场景**，确保闭包中使用的变量所有权转移到线程中。

## 迭代器（Iterator）

### 一句话理解

> **迭代器是对集合的"惰性遍历"——只有你开始消费时，它才真正执行。**

### 三个核心方法

```rust
let v = vec![1, 2, 3, 4, 5];

// 1. .iter() → 创建迭代器（不可变引用）
for val in v.iter() {
    println!("{}", val);  // 1, 2, 3, 4, 5
}

// 2. .iter_mut() → 可变引用迭代器
for val in v.iter_mut() {
    *val *= 2;
}
println!("{:?}", v);  // [2, 4, 6, 8, 10]

// 3. .into_iter() → 获取所有权
let v2 = vec![1, 2, 3];
for val in v2.into_iter() {
    println!("{}", val);
}
// println!("{:?}", v2);  // ❌ v2 所有权已被拿走
```

### 迭代器适配器（链式调用）

这些方法不会立即执行，它们只是**构建处理流水线**：

```rust
let numbers = vec![1, 2, 3, 4, 5, 6];

// .map()：对每个元素做转换
let doubled: Vec<i32> = numbers.iter().map(|x| x * 2).collect();
println!("{:?}", doubled);  // [2, 4, 6, 8, 10, 12]

// .filter()：筛选满足条件的元素
let evens: Vec<&i32> = numbers.iter().filter(|x| *x % 2 == 0).collect();
println!("{:?}", evens);  // [2, 4, 6]

// .take()：取前 N 个
let first_three: Vec<&i32> = numbers.iter().take(3).collect();
println!("{:?}", first_three);  // [1, 2, 3]

// .skip()：跳过前 N 个
let after_two: Vec<&i32> = numbers.iter().skip(2).collect();
println!("{:?}", after_two);  // [3, 4, 5, 6]

// .chain()：串联两个迭代器
let a = vec![1, 2];
let b = vec![3, 4];
let chained: Vec<&i32> = a.iter().chain(b.iter()).collect();
println!("{:?}", chained);  // [1, 2, 3, 4]
```

### 消费器（Consumers）

这些方法**立即执行**迭代器，产生最终结果：

```rust
let numbers = vec![1, 2, 3, 4, 5];

// .collect()：收集到集合中
let collected: Vec<i32> = numbers.iter().map(|x| x * 2).collect();

// .sum()：求和
let sum: i32 = numbers.iter().sum();
println!("{}", sum);  // 15

// .count()：计数
let count = numbers.iter().count();
println!("{}", count);  // 5

// .reduce()：归约
let product = numbers.iter().copied().reduce(|a, b| a * b);
println!("{:?}", product);  // Some(120)

// .fold()：带初始值的归约
let sum = numbers.iter().fold(0, |acc, x| acc + x);
println!("{}", sum);  // 15

// .any() / .all()：条件判断
let has_even = numbers.iter().any(|x| x % 2 == 0);  // true
let all_positive = numbers.iter().all(|x| x > 0);    // true

// .find()：查找第一个
let first_even = numbers.iter().find(|x| *x % 2 == 0);
println!("{:?}", first_even);  // Some(2)
```

### 常见链式模式

```rust
// 经典流水线：filter → map → collect
let result: Vec<i32> = (1..20)
    .filter(|x| x % 2 == 0)      // 筛选偶数
    .map(|x| x * x)              // 平方
    .take(5)                     // 取前 5 个
    .collect();

println!("{:?}", result);  // [4, 16, 36, 64, 100]
```

### 自定义迭代器（实现 Iterator Trait）

```rust
struct Counter {
    count: u32,
}

impl Counter {
    fn new() -> Self {
        Self { count: 0 }
    }
}

impl Iterator for Counter {
    type Item = u32;

    fn next(&mut self) -> Option<Self::Item> {
        self.count += 1;
        if self.count < 6 {
            Some(self.count)
        } else {
            None
        }
    }
}

let counter = Counter::new();
let result: Vec<u32> = counter.collect();
println!("{:?}", result);  // [1, 2, 3, 4, 5]
```

### 为什么迭代器是零成本抽象？

```rust
// 函数式写法（看起来有多次分配，实际没有）
let result: Vec<i32> = (1..100)
    .filter(|x| x % 2 == 0)
    .map(|x| x * 3)
    .collect();

// 编译器会优化成等价于手写 for 循环的代码
// 没有中间分配，没有额外开销
// 这就是 Rust 的"零成本抽象"
```

## 闭包 + 迭代器 = 最强组合

```rust
#[derive(Debug)]
struct Hero {
    name: String,
    hp: i32,
    is_alive: bool,
}

let heroes = vec![
    Hero { name: "亚瑟".into(), hp: 100, is_alive: true },
    Hero { name: "兰斯洛特".into(), hp: 0, is_alive: false },
    Hero { name: "梅林".into(), hp: 80, is_alive: true },
];

// 链式调用活着的英雄名字
let alive_names: Vec<&String> = heroes
    .iter()
    .filter(|h| h.is_alive)          // 只保留活着的
    .map(|h| &h.name)                // 提取名字
    .collect();

println!("{:?}", alive_names);  // ["亚瑟", "梅林"]
```

## 常见误区

```rust
// ❌ 以为迭代器会改变原集合
let v = vec![1, 2, 3];
let doubled: Vec<i32> = v.iter().map(|x| x * 2).collect();  // ✅ 创建新的
println!("{:?}", v);  // [1, 2, 3]（原集合不变）

// ❌ 忘记 collect 导致迭代器不执行
let v = vec![1, 2, 3];
v.iter().map(|x| println!("{}", x));  // ❌ 啥也不会打印（惰性）
v.iter().for_each(|x| println!("{}", x));  // ✅ 立即执行

// ❌ 闭包中类型不匹配
let result = v.iter().map(|x| {
    if x > 1 { x * 2 } else { x * 3 }  // 正确
});
```

## 性能建议

```rust
// ✅ 用迭代器链（会被优化成高效代码）
let r: i32 = (0..100)
    .filter(|x| x % 2 == 0)
    .map(|x| x * x)
    .sum();

// ✅ 等价于手写循环，但更清晰
// 编译后生成的机器码几乎一样

// ⚠️ 小心 collect 多次调用（会产生中间集合）
// ❌ 不好的做法
let even = (0..100).filter(|x| x % 2 == 0).collect::<Vec<_>>();
let sum: i32 = even.iter().map(|x| x * x).sum();

// ✅ 更好的做法
let sum: i32 = (0..100).filter(|x| x % 2 == 0).map(|x| x * x).sum();
```

> 关联知识点：泛型（Iterator 是泛型 Trait）、Trait、Vec
