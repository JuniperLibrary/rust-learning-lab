# 复合类型（Tuple / Array / Slice）

> 基础数据类型（整数、浮点、bool、char）可以拼成复合类型来组织数据。

## 是什么

Rust 有三种基本复合类型：

| 类型 | 元素类型 | 长度 | 分配位置 | 访问方式 |
|------|---------|------|---------|---------|
| 元组 `(T, U, V)` | 可以不同 | 编译时固定 | 栈 | `t.0` / 解构 |
| 数组 `[T; N]` | 必须相同 | 编译时固定 | 栈 | `a[i]` |
| 切片 `&[T]` | 必须相同 | 运行时确定 | 栈（胖指针） | `s[i]` |

## 怎么用

### 元组 (Tuple)

```rust
let t = (42, 3.14, 'R');         // 类型推断为 (i32, f64, char)
println!("{}", t.0);              // .0 .1 .2 访问元素
let (x, y, z) = t;               // 解构赋值

let mut mt = (1, "hello");
mt.0 = 42;                        // mut 元组可修改（但类型不能变）
```

### 数组 (Array)

```rust
let a: [i32; 3] = [1, 2, 3];     // 显式类型标注
let b = [0; 5];                   // [0, 0, 0, 0, 0]，简写
println!("{}", a[0]);             // 索引访问
println!("{}", a.len());          // 长度

// a.push(4);  编译错误！数组长度编译时固定
```

### Vec （复习 + 对比）

```rust
let v = vec![1, 2, 3];            // Vec<i32>，长度运行时可变
v.push(4);                        // OK
```

### 切片 (Slice)

```rust
let a = [1, 2, 3, 4, 5];
let s = &a[1..4];                 // [2, 3, 4]
let s2 = &a[1..=4];               // [2, 3, 4, 5]，包含右边
let s3 = &a[..];                  // [1, 2, 3, 4, 5]，全部

println!("{}", s.len());          // 3
```

切片是**借用**，不拥有数据。如果原数据被释放（drop），切片就无效了。

## 为什么

### 元组 vs 结构体
元组适合临时组合几个值（如函数返回多个值），比定义结构体轻量。但如果字段需要见名知意，应该用 struct。

### 数组 vs Vec
- 数组在栈上分配，零额外开销，长度编译时已知
- Vec 在堆上分配，有扩容开销，但长度灵活
- 优先用 Vec，仅在需要极致性能且长度确定时用数组

### 切片 vs 直接引用
切片比 `&Vec` 更通用 —— 函数参数用 `&[T]` 可以同时接受数组和 Vec：

```rust
fn sum(s: &[i32]) -> i32 { s.iter().sum() }
sum(&[1, 2, 3]);      // 数组
sum(&vec![1, 2, 3]);  // Vec
```

## 常见坑

- 元组索引不能用变量：`t.i` 不行，只能用字面量 `t.0`
- 数组越界在运行时 panic：`a[100]` 不会编译通过（但索引是变量时可能在运行时 panic）
- 切片范围 `a..b` 是**左闭右开**（包含 a，不包含 b），`a..=b` 是**全闭**
- 切片不拥有数据，生命周期受原数据限制
