# 泛型（Generics）

## 一句话理解

> **泛型是"类型参数化"：写一次代码，适用于多种类型。**

## 泛型函数

```rust
// 没有泛型：要为每种类型写一遍
fn max_i32(a: i32, b: i32) -> i32 { if a > b { a } else { b } }
fn max_f64(a: f64, b: f64) -> f64 { if a > b { a } else { b } }

// 用泛型：写一次就够了
fn max<T: PartialOrd>(a: T, b: T) -> T {
    if a > b { a } else { b }
}

println!("{}", max(3, 5));        // 5（i32）
println!("{}", max(3.14, 2.71));  // 3.14（f64）
```

`<T>` 是**类型参数**（type parameter），调用编译器自动推断具体类型。

## 泛型结构体

```rust
struct Point<T> {
    x: T,
    y: T,
}

let int_point = Point { x: 5, y: 10 };     // Point<i32>
let float_point = Point { x: 1.0, y: 2.0 }; // Point<f64>

// 泛型结构体搭配泛型方法
impl<T> Point<T> {
    fn x(&self) -> &T {
        &self.x
    }
}

// 也可以为特定类型实现额外方法
impl Point<f64> {
    fn distance_from_origin(&self) -> f64 {
        (self.x.powi(2) + self.y.powi(2)).sqrt()
    }
}
```

## 多个类型参数

```rust
struct Pair<T, U> {
    first: T,
    second: U,
}

let pair = Pair { first: "hello", second: 42 };  // Pair<&str, i32>
```

## 特征约束（Trait Bounds）

```rust
// 方式一：尖括号内约束
fn max<T: PartialOrd>(a: T, b: T) -> T { /* ... */ }

// 方式二：where 子句（约束多时更清晰）
fn max<T>(a: T, b: T) -> T
where
    T: PartialOrd + Display,
{ /* ... */ }

// 多个约束
fn complex<T, U>(t: T, u: U) -> String
where
    T: Display + Debug,
    U: Clone,
{ format!("{:?} {}", t, u.clone()) }
```

### 常见特征约束

| 约束 | 作用 | 例子 |
|------|------|------|
| `PartialOrd` | 可比较大小 | 排序、max/min |
| `PartialEq` | 可判断相等 | 查找、去重 |
| `Display` | 用户可读输出 | `{}` 格式化 |
| `Debug` | 调试输出 | `{:?}` 格式化 |
| `Clone` | 显式拷贝 | 需要副本时 |
| `Copy` | 按位拷贝 | 简单值传递 |
| `Default` | 默认值 | 构造空实例 |

## 泛型 vs 特征对象（运行时）

```rust
// 编译期静态分派（泛型）：每种 T 生成一份代码
// 优点：零运行时开销，可内联优化
// 缺点：编译产物更大（monomorphization）
fn print_static<T: Display>(item: T) { println!("{}", item); }

// 运行时动态分派（dyn）：运行时通过虚表调用
// 优点：一份代码适用于所有类型
// 缺点：略慢（间接调用），不能内联
fn print_dynamic(item: &dyn Display) { println!("{}", item); }

// 什么时候用哪个？
// - 泛型：绝大多数场景，性能敏感
// - dyn Trait：需要存储异构类型集合时（如 Vec<Box<dyn Display>>）
```

## 泛型与性能

```rust
// Rust 的泛型是零成本抽象（zero-cost abstraction）
// 编译时会做单态化（Monomorphization）
let int_max = max(3, 5);        // 编译后等价于 max_i32
let float_max = max(1.0, 2.0);  // 编译后等价于 max_f64

// 运行时没有任何额外开销，也没有虚函数调用
// 但缺点是编译产物会变大（每个类型生成独立函数）
```

## 对比其他语言

| 特性 | Rust 泛型 | C++ 模板 | Java 泛型 |
|------|----------|---------|-----------|
| 实现方式 | 单态化（Monomorphization） | 模板实例化 | 类型擦除（Type Erasure） |
| 运行时开销 | 零 | 零 | 有（装箱/拆箱） |
| 编译产物 | 每种类型独立代码 | 每种类型独立代码 | 一份字节码 |
| 运行时类型信息 | 无 | 无（除非虚函数） | 有（反射） |
| 约束机制 | Trait Bounds | SFINAE/Concepts | 通配符/边界 |

## 常见误区

```rust
// ❌ 泛型函数不支持运算符（除非约束）
// fn add<T>(a: T, b: T) -> T { a + b }  // ❌ 不是所有类型都支持 +
fn add<T: std::ops::Add<Output = T>>(a: T, b: T) -> T { a + b }  // ✅

// ❌ 泛型不能直接用于运行时类型判断
// fn check<T>(x: T) {
//     if x is String { ... }  // ❌ Rust 没有运行时类型识别
// }

// ✅ 用 trait 或枚举处理运行时多态
fn process(x: &dyn Any) { /* ... */ }

// ⚠️ 多个泛型参数时类型推断可能失败
let p = Pair { first: 1, second: 2.0 };       // ✅ 自动推断
let p = Pair::<i32, f64> { first: 1, second: 2.0 };  // ✅ 也可以手动指定
```

> 关联知识点：Trait（特征约束）、Iterator（迭代器都基于泛型）
