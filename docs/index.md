## 🎯 学习原则

- **动手 > 看书**：每个知识点都有对应的可运行代码
- **渐进式**：基础 → 进阶 → 实战，不要跳过
- **用自己的话总结**：笔记不是抄文档，是理解后的提炼
- **优先理解"为什么"**：Rust 的设计决策背后都有深刻的工程考量
